# Corrida-de-Kart-Turbinado
Este projeto, desenvolvido para a aula de Coding da UniNorte, consiste na criação de um sistema de corrida de Kart. Simulação de 3 voltas (loop for). O jogador escolhe acelerar, frear ou usar nitro. Condicionais lidam com o desgaste dos pneus e matemática calcula o tempo final.

Como rodar?
Rodar direto no navegador 
(Mais rápido)

1. Copie o código gerado acima.
2. Acesse o site oficial: play.kotlinlang.org.
3. Cole o código no editor central, substituindo tudo o que estiver lá.
4. Clique no botão "Run" (canto superior direito).
5. O console interativo abrirá na parte de baixo para você digitar as ações da corrida.
   
Se você já tiver o SDK do Kotlin instalado:

1. Cole o código em um arquivo de texto e salve com o nome Corrida.kt.
