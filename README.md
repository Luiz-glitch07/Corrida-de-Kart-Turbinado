# Corrida-de-Kart-Turbinado
Este projeto, desenvolvido para a aula de Coding da UniNorte, consiste na criação de um sistema de corrida de Kart. Simulação de 3 voltas (loop for). O jogador escolhe acelerar, frear ou usar nitro. Condicionais lidam com o desgaste dos pneus e matemática calcula o tempo final.
